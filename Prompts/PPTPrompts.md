# Prompt Engineering Best Practices

An effective PowerPoint prompt should specify:

- Business Context
- Target Audience
- Presentation Purpose
- Number of Slides
- Presentation Duration
- Visual Style
- Output Requirements

---

## Example

Instead of asking:

> Create a presentation.

Ask:

> Create a 12-slide Board presentation summarizing our AI Transformation Strategy. Include executive visuals, speaker notes, roadmap, KPIs, governance, investment priorities, and recommendations. Use a Fortune 500 consulting style.

# Best Practices

- Begin with a structured Word document as the source.
- Clearly specify the target audience (Board, Investors, Leadership, Employees).
- Define the expected number of slides and presentation duration.
- Request speaker notes and executive takeaways for every slide.
- Use Copilot to generate the first draft, then refine through iterative prompts.
- Validate business facts, financial figures, and recommendations before presenting.
- Keep slides focused on outcomes, decisions, and business value rather than technical details.
