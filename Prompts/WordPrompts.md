---

# Prompt Engineering Best Practices

A high-quality prompt should include:

- Business Context
- Objective
- Expected Output
- Audience
- Format
- Tone
- Constraints

Example

Instead of asking

> Summarize this document.

Ask

> Summarize this 60-page Board Report for the CEO. Include financial performance, risks, customer insights, strategic opportunities, and executive recommendations. Keep the summary within one page.

# Universal Prompt Refinement Techniques

After Copilot generates the first response, continue refining with prompts such as:

### Make it shorter

```text
Reduce this to one page.
```

---

### Make it executive friendly

```text
Rewrite using Board-level language.
```

---

### Improve readability

```text
Use bullet points instead of paragraphs.
```

---

### Add recommendations

```text
Include actionable executive recommendations.
```

---

### Focus on AI

```text
Highlight AI opportunities discussed in the report.
```

---

### Focus on Risks

```text
Expand the Risk Analysis section.
```

---

### Create Tables

```text
Present findings as executive tables.
```

---

### Prioritize

```text
Rank recommendations from highest to lowest business value.
```

---

### Compare

```text
Compare current performance with previous quarters.
```

---

### Executive Tone

```text
Rewrite this as if presenting to Fortune 500 CEOs.
```

# Best Practices

- Provide complete business documents instead of isolated paragraphs.
- Mention the target audience (CEO, Board, Investors, Employees).
- Specify the desired output format (table, summary, report, action plan).
- Request measurable outcomes wherever possible.
- Refine prompts iteratively instead of expecting perfection from a single prompt.
- Validate AI-generated content before using it in executive decision-making.
